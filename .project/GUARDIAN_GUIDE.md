# คู่มือผู้พิทักษ์แบบเลือกคำถาม

ยกเลิกระบบ AI / Copilot ตามคำขอผู้จัด ผู้ช่วยใช้หัวข้อที่เตรียมไว้ใน `src/lib/guardian-guide.ts` และข้อมูลคณะที่ตรวจสอบไว้ใน `src/data/faculty-knowledge.ts` กดหัวข้อแล้วอ่านคำตอบทันทีในเบราว์เซอร์ ไม่เรียก API ผู้ช่วย ไม่ใช้โควตา AI และไม่ต้องตั้ง GitHub token

ข้อมูลรางวัลอ่านกติกาที่เผยแพร่ใน Firebase เดิม คำถามที่พบบ่อยของผู้จัดอ่านจาก CMS เฉพาะรายการเผยแพร่ ส่วนข้อมูลรับสมัครและช่องทางติดต่อมีเอกสารอ้างอิงและวันที่ตรวจ แยกปี 2570 กับย้อนหลัง 2569 ชัดเจน ดูหลักฐานใน `ASSISTANT_SOURCES.md` และปรับข้อมูลเมื่อมีประกาศใหม่

หมวด: ร่วมงาน / สมัครเรียน / รู้จักคณะ / ติดต่อ / เจ้าหน้าที่ คู่มืองานเจ้าหน้าที่ไม่ให้สิทธิ์ทำรายการแทนหน้าจริง

กด × ข้างสัตว์เลี้ยง หรือปุ่มซ่อนในหน้าต่างคู่มือ เพื่อซ่อนตัวละคร สถานะเก็บใน localStorage ของเบราว์เซอร์ (`fatu_guardian_hidden`) เมื่อเปลี่ยนหน้าหรือรีเฟรชยังซ่อนอยู่ ปุ่มเล็ก “ผู้ช่วย” ใช้เรียกสัตว์เลี้ยงกลับมา หน้าคู่มือ `/assistant` ยังเปิดได้

ตรวจสอบ: `npm run test:assistant`, `npm run test:assistant-ui` (เปิด Vite dev server ก่อน), `npm run check`
