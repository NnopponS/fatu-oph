# Fixed 2026 media

Put authored assets that rarely change here.

Examples:
- approved venue reference photos
- generated background art
- optimized Google Flow loops
- poster fallbacks
- fixed FATU Open House 2026 marks

These files are deployed with the Vercel application and referenced as /media/<filename>.

Do not put participant uploads, admin-editable content, secrets, or private documents here.
Dynamic admin-managed media belongs in Vercel Blob.
